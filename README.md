Django CRUD API with Authentication

This project demonstrates how to build a CRUD (Create, Read, Update, Delete) API using Django and Django Rest Framework (DRF). The API is secured with token-based authentication provided by DRF. Features

CRUD operations for managing posts (Create, Read, Update, Delete).
Token-based authentication for secure API access.
Built using Python and Django Rest Framework.

Tech Stack

Backend Framework: Django, Django Rest Framework
Database: SQLite (default for Django; can be changed to PostgreSQL, MySQL, etc.)
Authentication: Token-based authentication

Installation Prerequisites

Python 3.8+
pip (Python package manager)
Create the Virtual environment and activate it after that install Django in it.
